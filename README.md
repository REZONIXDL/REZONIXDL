## 🚀 What I'm building

### [Anik](https://github.com/REZONIXDL/Anik) — Offline AI Product Photo Studio
Android app in **Kotlin / Jetpack Compose** (v3.2.0) that turns phone photos into clean product shots:

- On-device background removal with **U2NetP + LiteRT** — no photo leaves the phone
- Site theme engine: paste a website link and get its full brand theme (colors, gradients, WCAG contrast)
- Classic + smart + touch-up engines, before/after compare, transparent PNG export, batch processing, story / portrait / square presets
